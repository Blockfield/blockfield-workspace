# Blockfield

Игра для небольшой компании друзей (до ~10 человек): клиентский пак, игровой сервер и инструменты вокруг них.

## Language

**Модуль**:
Часть игры, которую меняют и выпускают без остальных частей.
_Avoid_: репозиторий (как синоним модуля), сервис

**Контент**:
Баланс, карты и классы: всё, что меняется данными без нового кода игры.
_Avoid_: настройки (как синоним контента), ассеты

**Класс**:
Набор снаряжения с вариантами, режимами, где он доступен, стоимостью и лимитом игроков.
_Avoid_: кит, kit, loadout

**Платформа**:
Части проекта, через которые контент попадает в игру без нового кода.
_Avoid_: инфраструктура (как синоним платформы)

**Control plane**:
Единственный источник состояния и канал команд для игры, proxy, Workshop, сайта и лаунчера.
_Avoid_: CP-сервер, центральный узел

**Сайт**:
Витрина и админка для людей, клиент control plane; другие части от него не зависят.
_Avoid_: сайт как источник настроек или статистики

**Публичный запуск**:
Открытие игры для незнакомых игроков, после которого играют не только друзья.
_Avoid_: «публичный» в смысле открытого кода или публичного репозитория
