# Игровые инварианты

Менять только по решению владельца (дословно в бэклог). Приёмка — сценарием до/после.

- Хитрег: сначала основной путь (тикет клиента → сервер откатывает цель к позе, которую видел стрелок), затем серверный
  fallback без тикета (минимальный RTT стрелка за последние 2 с, откат не больше 7 тиков, только пули игроков). Серверную проверку и окна
  времени не ослабляют; тикет — доказательство, а не решение. Приёмка: FN ≤ 5 %, FP ≤ 2 %, тикеты ≥ 95 %, по ≥ 30 выстрелов
  на когорту с доверительным интервалом Вилсона.
- Нож: набор анимаций и привязку «кнопка → анимация» без решения владельца не меняют (комбо ЛКМ как в релизе);
  хитбокс удара следует проигрываемой сейчас анимации; удар ПКМ срабатывает.
