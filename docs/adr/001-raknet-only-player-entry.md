# ADR 001: только RakNet для входа игроков

- Статус: принято (решение владельца 2026-10-18).
- Игрок подключается обычным vanilla-экраном к адресу вида `raknet;…`,
  без TCP-повтора; недоступный UDP даёт обычный экран отключения.
- Проверено: mod `docs/DEVELOPMENT-REFERENCE.md` («Игрок входит только
  по RakNet»), пин `client/` содержит Raknetify, протокол мода — ADR 002.
- TCP остаётся для status ping и для dev-стендов, идущих напрямую
  к локальному backend.
- Владелец транспортного контракта: proxy (`blockfield-proxy` README).
  Проверка отклонения TCP-логинов на стороне proxy здесь не
  верифицирована (приватный репозиторий).
